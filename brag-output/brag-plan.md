# Brag Plan: StudentAI

## What is this app?
StudentAI is an AI-powered academic success platform for college students — it doesn't just show your CGPA, it predicts where you're headed and flags at-risk subjects before finals, via a Gemini-powered assistant, OCR marksheet digitization, and attendance/grades intelligence.

## The angle
A premium EdTech launch film: quiet confidence, forward-looking momentum. The premise is that every student already has the data to predict their own academic future — most just read it too late. StudentAI reads it for you, continuously, and course-corrects before the problem lands. Shot on the product's own obsidian + violet-aurora design language.

## Hook (first 2-3 seconds)
Two-line cold open on obsidian black, violet glow bloom breathing behind:
"Your CGPA is already predicting your future."
"Most students read it too late."
The glow is the audio-reactive element — it breathes with the music bed from frame one.

## Key moments (the middle)
- **The dashboard reveal**: CGPA gauge counting up (8.65 / 10), stat cards arriving one by one (CGPA, Classes Today, Subjects, Low Alerts) — the product's real card surface, exact palette.
- **The assistant, in use**: "mark me present for DBMS today" types out character by character into the AI command bar; a row in the attendance list flips to PRESENT with a success state. The product doing its thing.
- **The predictor, forward-looking**: "Target 9.0" — the trajectory chart draws actual SGPAs (9.19 → 8.65) then projects forward; "Required SGPA each remaining semester: 8.9" banner lands beneath.

## Outro / punchline
"StudentAI." on a violet-gradient wordmark, then:
"Know where you're headed."
Tiny URL line: demo at studentai.app. Music holds, single soft bell.

## User flow worth showing
Entry → key action → result:
1. Open the dashboard → CGPA gauge + stat cards (entry)
2. Type a natural-language command → Gemini executes it as a real validated write (key action)
3. Predict a target CGPA → trajectory + required-SGPA insight (result)
This is the centerpiece material: the working app, not the landing page.

Beat grid every ~0.55s. Lock 1-2 majors (dashboard reveal ≈ 8.74s, predictor result ≈ 17.47s) within ±0.15s; snap stat-card arrivals to nearby beats within ±0.10s.
- Audio-reactive treatment: subtle; use music RMS/bass to make the violet hero glow breathe and product cards gain presence. No waveform/equalizer visuals.
- SFX posture: minimal (polished = 2-3 cues): a soft keyboard set while the command types, one gentle announcement when the predictor result lands, one bell on the outro wordmark. Nothing aggressive.
